A note on accuracy

Claude's features, models, and best practices change quickly. Each note records the date I wrote it and the course version where applicable, so some details may be out of date. If you spot an error or something outdated, please open an issue.

What you won't find here

To respect the course creators, this repo does not include:

Copied slides, transcripts, or video content
Quiz or exam questions and answers
Certificates or personal account information
Contributing
